# arXiv Filter 使用教程（小白版）

> 这是一份「怎么用」的说明，不涉及原理。照着做即可。

---

## 一、这是什么

一个**在你自己电脑上运行**的小工具，用来把 arXiv 上的新论文筛成一份阅读清单。

它帮你做三件事：

1. 按**分类 + 日期 + 关键词**去 arXiv 找论文；
2. 把结果去重、排序、缓存到你电脑本地；
3. 导出成 Excel / CSV / Markdown / JSON / BibTeX，方便记笔记或写论文引用。

**它不是什么**：不是 arXiv 官方产品，也不需要注册账号，更不需要联网登录任何服务。

---

## 二、怎么开始

### 打不开？看这里

- **第一次打开会慢一点**（几秒到十几秒），因为系统要扫描一遍文件，属正常现象。
- **双击后没反应**：可能被 Windows Defender 拦了。点「更多信息」→「仍要运行」。
- 程序**不会安装**到系统里，删掉文件夹就等于卸载。

### 启动后会发生什么

会**自动打开你的默认浏览器**，显示一个本地页面。这个页面**只在你自己的电脑上**能访问，别人访问不到。

### 怎么退出

两种都行：

- 点页面右上角的 **「退出」**；
- 或者**直接关掉浏览器标签页**——程序会等一小会儿自动退出。

> 如果关了页面程序还在后台，任务管理器里结束 `arxiv-filter.exe` 即可。

## 三、从零开始筛一次论文（5 步）

### 第 1 步：确认分类

页面上「搜索条件」里已经有默认值：

| 字段 | 默认值 | 说明 |
|---|---|---|
| 一级分类 | **数学 · Mathematics** | 大类 |
| 二级分类 | **偏微分方程分析 · math.AP** | 小类，可以改 |

- **不确定选哪个小类**？把二级分类选成「**全部子类**」，就会搜这个大类的全部论文。
- 想找别的方向，直接在下拉框里换（计算机科学、物理、统计等共 8 个大类）。

### 第 2 步：确认日期范围

起始日期与截止日期**默认已经填好最近 7 天**。

想换范围，两种方式：

- 点右侧的快捷按钮：**3 天 / 7 天 / 30 天 / 本月**；
- 或者直接手动选日期。

> ⚠️ **日期是 UTC（世界时）**，不是北京时间。北京时间比 UTC 早 8 小时，所以「今天」的边界会差 8 小时。
>
> ⚠️ **节假日查不到是正常的**：arXiv 在**周日到周四**公布论文，**周五、周六不公布**。如果某天筛出来是 0 篇，先看看那天是不是周五或周六。

### 第 3 步：填关键词（可选）

**留空也能搜**，那就只按分类和日期筛选。

想缩小范围就填关键词。常用写法：

| 你想要的效果 | 这样写 |
|---|---|
| 三个词**都要有**（交集） | `PDEs AND Hessian AND estimate` |
| 同上，简写 | `PDEs Hessian estimate` |
| **精确短语** | `"partial differential equation"` |
| 满足其中一个 | `PDE OR PDEs` |
| **排除**某个词 | `PDE NOT survey` |
| 组合 | `(PDE OR PDEs) AND Hessian NOT survey` |

三个要点：

1. **`AND` / `OR` / `NOT` 两边要有空格**，大小写随意；
2. **词与词之间不写 `AND` 也默认是「都要有」**，所以 `PDEs Hessian estimate` = `PDEs AND Hessian AND estimate`；
3. **不要用逗号分隔**——`PDEs, Hessian` 会被当成一个带逗号的词，搜不到东西。

旁边的「**搜索范围**」决定在哪儿找这些词：全部字段 / 仅标题 / 仅摘要 / 仅作者。默认「全部字段」最容易搜到。

### 第 4 步：点「开始筛选」

其他两个选项看不懂就别动：

| 选项 | 默认 | 说明 |
|---|---|---|
| 排序 | 提交时间倒序 | 最新的排前面 |
| 结果上限 | 2000 | 最多取多少篇；取太大会慢 |

筛选过程中：

- 上方会显示进度；
- 想中断就点「**取消查询**」；
- **此时下方仍显示上一次的结果**，不会白屏。

### 第 5 步：看结果

每张卡片可以：

- **点标题** → 在新标签页打开 arXiv 原文页面；
- **展开摘要** → 就地看摘要，不用跳走；
- **标记已读 / 标记未读**；
- **复制引用** → 复制一段可粘贴的引用文字。

结果多的时候用底部的「**上一页 / 下一页**」翻（每页 50 条）。

## 四、让清单更好用

### 只看新增 / 只看未读

结果区右上角有个下拉框：**全部论文 / 只看新增 / 只看未读**。

- **新增** = 这次筛选出的、你以前没见过的论文；
- **未读** = 你还没手动标记为已读的。

> 「新增」是按**卡片的显示状态**判断的，滚动浏览**不会**自动把它标成已读——所以你不会因为翻页而漏掉论文。

### 「继续获取」

如果结果被「结果上限」截断了，结果区会出现「**继续获取**」按钮，点一下再取 2000 篇。

### 导出

点结果区右上角的「**导出**」，会弹出对话框：

| 格式 | 什么时候用 |
|---|---|
| **CSV · Excel 兼容** | 想在 Excel 里自己排序、筛选 |
| **Excel 工作簿（.xlsx）** | 直接给 Excel 打开，已设好表头与筛选 |
| **JSON · 完整元数据** | 要拿去做进一步处理 |
| **Markdown · 阅读笔记** | 粘进笔记软件（Obsidian、Typora 等） |
| **BibTeX · 文献引用** | 写论文时给 LaTeX / Zotero 用 |

两个勾选项：

- **包含新增 / 已读状态**（默认勾选）：导出文件里带上这些标记；
- **未完成的部分结果**：只有筛选被中断、结果不完整时才会出现，需要你确认一次。

> 导出的是**当前筛选条件下的全部结果**，不只是当前这一页。

### 查询历史

点右上角「**查询历史**」，可以看到以前的筛选条件，点一下就**把条件填回表单**，不用重新选一遍。

### 重置条件

「搜索条件」右上角的「**重置条件**」会把所有字段恢复成刚打开时的样子（默认分类、最近 7 天、关键词清空）。

## 五、数据放在哪 / 会不会泄露

所有数据都在你自己的电脑上：

```text
C:\Users\<你的用户名>\AppData\Local\ArxivFilter\
```

- `arxiv-filter.db` —— 论文缓存、查询历史、已读状态
- `exports\` —— 你导出的文件
- `logs\` —— 运行日志（排查问题时用）

**会联网的部分只有一件事**：把你的筛选条件发给 arXiv 的公开接口去取论文列表。除此之外不上传任何东西，不需要账号。

> 页面底部「关于与声明」里也写了这一点，可以直接给使用者看。

## 六、常见问题

**Q：一次都没搜到结果？**
按顺序检查：
1. 日期范围是不是太窄？先放宽到 30 天试试；
2. 那天是不是**周五或周六**？（arXiv 不公布）
3. 关键词是不是太苛刻？先把关键词清空，只按分类+日期搜；
4. 二级分类是不是选太细？改成「全部子类」。

**Q：点了筛选一直转圈 / 报错说请求过于频繁？**
这是 arXiv 那边的限流。等一会儿再点，或者把日期范围调小一点。
**不要连续快速点「开始筛选」**——程序内部已经做了防重复，但频繁重试只会让等待更久。

**Q：界面显示「找到一份过期缓存」是什么意思？**
表示这次查询没成功，但本地有一份**之前**抓的同样条件的结果。点「确认使用」就能先看这份旧数据。

**Q：换了个文件夹/盘符，数据还在吗？**
在。数据固定存在上面那个 `AppData\Local\ArxivFilter`，跟程序放哪儿无关。

**Q：想清空所有缓存和已读记录？**
点「设置」→「**清理缓存**」。注意这会清掉缓存的论文，但**保留**你的已读标记。

**Q：公司/学校网络需要代理？**
点「设置」→「网络代理」，可以选「使用系统代理」或填自定义代理地址。

## 七、给别人传的时候

**只传这一个文件就够了**：

```text
arxiv-filter.exe
```

对方双击即可运行，不需要安装 Python 或任何依赖。

几点提醒：

- 对方电脑需要是 **Windows 10 1803 或更高版本**（64 位）；
- 第一次运行 Windows 可能弹 SmartScreen 提示（因为文件没有数字签名），点「更多信息」→「仍要运行」；
- 对方的**数据和你的完全独立**，各存各的，不会互相看到；
- 程序不会自动更新，有新版本要重新传文件。

> 想省心的话，也可以用压缩包把「onedir」那一版整个文件夹发过去，启动更快、不用每次解压。
